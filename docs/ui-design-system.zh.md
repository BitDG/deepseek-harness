# DSH 界面设计系统

[English](ui-design-system.md) | 中文

## 概述

使用本参考将现有控件与主题变量组合成 DSH 界面。在“设置 → 界面组件”中，可以用示例数据试用生产组件。展示页覆盖基础控件、输出卡片、视觉变量和组合状态；示例操作不会执行命令或保存文件。“浅色”和“深色”按钮会修改真实外观偏好。

<a id="component-selection"></a>
## 组件选择

[原子组件目录](../packages/client/ui-primitives/README.zh.md#component-catalog)维护导出参数与行为。[交互展示页包](../packages/client/ui-design-system/README.zh.md)维护演示行为。新增控件前先查阅这些权威来源。

| 意图 | 组件 | 选择规则 |
|---|---|---|
| 明确操作 | `Button` | 区域内明确主操作使用 `accent`；中性强调使用 `primary`；次要操作使用 `outline`；弱化操作使用 `ghost`；成组工具使用 `toolbar`。 |
| 单行输入 | `Input` | 每个输入框提供可见标签或可访问名称。校验信息紧邻输入框，通过 `aria-describedby` 关联；无效值设置 `aria-invalid`。 |
| 双态选择 | `Switch`、`Checkbox` | 即时开关选项使用 Switch，包含或确认选择使用 Checkbox。传入选中状态与本地化标签。 |
| 筛选或事实 | `Pill`、`Tag` | 可交互胶囊切换选择；标签陈述事实，不模仿按钮。 |
| 状态 | `StateDot`、`ConnectionIndicator` | 状态点旁放文字说明；连接反馈明确重试动作，并区分重试中与已恢复。 |
| 隐藏详情 | `DisclosureRow` | 标题行保持稳定，按需展开详情。 |
| 临时内容 | `Menu`、`Tooltip`、`HoverCard` | 菜单承载操作，提示补充标签，悬停卡片承载可阅读预览。关键信息无需悬停也可获取。 |
| 确认或通知 | `Modal`、`RiskConfirmation`、`Toast` | 弹窗说明后果并允许取消；风险确认要求显式勾选；通知报告已观察到的结果。 |
| Agent 输出 | `TerminalBlock`、`ReadBlock`、`DiffBlock`、`SearchBlock`、`WebBlock` | 按结果含义选择；保留路径、退出状态、行号、总数与截断信息。 |
| 富内容 | `MarkdownText`、`CodeBlock`、`JsonTree` | 使用现有安全渲染与复制行为，不渲染模型提供的原始 HTML。 |
| 身份或文件分类 | 共享图标、`FishLogo`、`BrandWordmark`、`FileTypeIcon`、`ReferenceIcon`、`LinkIcon` | 复用共享图形与分类，不绘制功能专属替代品。 |

<a id="visual-rules"></a>
## 视觉规则

[Web 样式参考](web-styling.zh.md)维护样式政策，[主题源码](../packages/client/ui-theme/src/styles/)维护变量值与亮暗映射。展示页色块与产品控件使用相同变量，选择文字即可复制变量名。本文与功能样式均不维护第二套色板。

- 背景、文字、交互、边框与状态使用 `--dsw-alias-*` 语义颜色。每个区域仅为一个明确主操作保留强品牌强调。
- 界面文字使用 `--dsw-font-family`，代码与变量名使用 `--ds-font-family-code`。每个字号搭配行高；适用时复用现有主题字体角色。
- 标准 `Button` 高 36px、r18；紧凑按钮高 28px、r14；`Switch` 为 36×20px；`DisclosureRow` 高 24px。`Input` 外框高 32px、r8。这些由组件维护的尺寸不规定任意列表或表格尺寸。
- 按关系选择间距：相邻控件间距小于独立区域间距。展示页使用 4/8/12/16/24px；本文不引入新的全局间距变量命名空间。
- 中性实线边框与分隔线使用 0.5px。浮起表面使用现有层级阴影，不叠加第二道中性边框。状态色边框维持所属组件的宽度。
- 胶囊与圆形的全圆角配合 `corner-shape: round`；其余圆角表面在支持的浏览器中继承主题平滑曲率。
- 过渡沿用主题时长与曲线。尊重 `prefers-reduced-motion`；理解进度或状态不依赖动效。

<a id="composition-and-feedback"></a>
## 组合与反馈

导航、集合、列表与阅读或编辑内容位于稳定的相邻区域。功能插件通过插槽接入现有外框。标题、页签与图标操作在所属标题栏中对齐；首个可选择行与标题分隔线保持可见距离。

| 情况 | 必需的可见信息 | 恢复或操作 |
|---|---|---|
| 加载 | 指明待完成操作，保留对象并禁止重复提交。 | 所属操作支持取消时保留取消入口。 |
| 空集合 | 说明缺少什么内容。 | 提供适用的新建或导入操作。 |
| 筛选无匹配 | 说明当前筛选没有匹配项。 | 提供清除筛选操作。 |
| 失败 | 说明失败对象与仍可使用的部分，保留可读文字。 | 仅在支持时提供重试或修正操作。 |
| 完成 | 操作成功后才报告成功。 | 保留可见的结果对象或已保存状态。 |
| 文件或外部数据 | 按场景指明来源与选中文件、分支、文件夹、工作表或笔记。 | 区分草稿、本地保存与已完成的远端操作。 |

展示页的“组合规范”使用本地示例数据演示筛选空态与可重试错误。标签和通知描述示例，不表示真实文件保存或远端请求。

<a id="interaction-and-accessibility"></a>
## 交互与可访问性

通过有类型的语言字典提供控件的本地化可见文字与可访问名称。无边框控件保留可见键盘焦点；有边框输入框使用自身焦点边框。禁用状态保留上下文并阻止操作；加载状态还需描述正在进行的操作。

菜单保持共享键盘行为：方向键及 Home/End 移动，Enter 或 Tab 选择焦点行，Escape 或 Shift+Tab 关闭并返回触发按钮。展示页页签仅保留一个 Tab 停靠点，支持左右方向键及 Home/End。嵌套示例弹窗先于设置外框处理 Escape，将 Tab 限制在自身控件内，并在关闭后返回触发按钮。生产界面的拥有者需验证自身弹窗的焦点限制与恢复；仅使用 `Modal` 不会自动获得这些拥有者行为。

状态不单靠颜色表达。错误文字指明修正动作。提示补充标签，关键操作始终可直接访问。较长源码输出保留列位置，并提供共享滚动与复制控件。

<a id="implementation-and-verification"></a>
## 实现与验证

编写控件前先复用 [ui-primitives](../packages/client/ui-primitives/README.zh.md)。第二个功能需要的控件归入该包；有意的视觉差异通过参数表达，不复制实现。业务数据、本地化与组合留在所属功能内。共享运行时代码不从一个功能插件导入另一个功能插件。

展示页注册到 `settings.section`，通过现有主题服务写入外观偏好。其余演示使用组件局部状态与固定示例内容。该包仅导出加载入口，使用 CSS Modules 与语义主题变量，不增加模型工具、提示词或会话事件。

通过包类型检查、针对性交互测试及真实 Web 组合验证变更。检查亮暗渲染、键盘导航、弹窗焦点恢复、复制与折叠、空态与错误恢复，以及桌面尺寸变化。截图展示外观，交互 GIF 记录运行页面。静态图谱说明影响范围，不证明运行成功。

## 开发备注

交互页选取最常用的共享控件与输出渲染器；原子组件 README 仍是完整导出目录。业务专属的对话组合与引导留在所属包中。
